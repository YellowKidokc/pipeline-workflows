# 03 — Workflows

## What this folder is

Workflow job files that chain stations together in a defined order. Think of these as recipes.

## Process

Each workflow is a .py or .job file that calls stations in sequence. The core NLP pipeline lives here. Run START.bat to launch a workflow manually, or let 07_ORCHESTRATOR trigger it automatically from a file drop.
