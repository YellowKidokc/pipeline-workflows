# 23_CPEL

Claims, Proofs, Evidence, Lean. Four API calls per paper.

The prompts for this station are one folder per call under `calls/`:
`001_CLAIMS`, `002_PROOFS`, `003_EVIDENCE`, `004_LEAN`. Each has `prompt.md` (what the model
is told) and `output.md` (the shape it fills). Order and on/off switches are in `ckg.json`.
Extra focus from `FOCUS.md` or the menu is added to every call.
