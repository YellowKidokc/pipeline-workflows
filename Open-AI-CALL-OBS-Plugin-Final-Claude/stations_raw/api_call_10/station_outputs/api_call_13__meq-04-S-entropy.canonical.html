Domain specifications

Domain A · Physics

Entropy & the Second Law — In any isolated system, entropy never decreases. The Boltzmann entropy S = kB ln Ω measures the number of accessible microstates. The law is statistical, directional, and irreversible on macroscopic scales.

Clausius (1865), Boltzmann (1877) · dS ≥ 0

Domain B · Theology

The Fall & the Curse — Creation was subjected to futility (mataiotēs) not by its own choice, but by the one who subjected it, in hope. Decay, death, and disorder enter the created order as a consequence of rebellion. The condition is universal, directional, and awaits redemption.

Gen 3:17–19 · Rom 8:20–22 · 1 Cor 15:21

Separator tests

Test A · Structural preservation

Do relations survive under mapping? The inequality dS ≥ 0 maps to ∂δ/∂t ≥ 0; the partial order of microstates maps to the ordering of creation‑states under futility.

PASS

Test B · Non‑arbitrariness

Could entropy map to something else? The directional, statistical, and terminal features uniquely align with the Fall narrative; swapping targets (e.g., Incarnation) loses the irreversible decay structure.

PASS

Test C · Constraint

Does the mapping rule things out? It forbids any theology where the Fall is reversible by human effort, and any physics where entropy decreases spontaneously in isolated systems.

PASS

Test D · Bidirectionality

Does each side predict the other? The Second Law predicts a “subjected” creation; the Fall predicts a thermodynamic arrow. Both point to a contingent, directional, non‑eternal universe.

Falsification criteria

The isomorphism is falsified if any of the following obtain:

  • ✓   Entropy is found to decrease spontaneously in an isolated system (violation of Second Law).
  • ✓   The Fall is shown to be a reversible event (i.e., creation can return to pre‑Fall state by natural processes).
  • ✓   A non‑theological account of the Second Law eliminates the need for any “subjected” condition.
  • ✓   The mapping between microstate multiplicity and creation‑state multiplicity is broken by a discovery of a non‑statistical origin of the Second Law.
  • ✓   Eschatological restoration is demonstrated to be impossible in principle (contradicts limit correspondence).
