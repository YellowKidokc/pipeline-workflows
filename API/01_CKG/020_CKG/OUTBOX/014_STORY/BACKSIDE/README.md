# 14_STORY

Story Material System v1.0 (pilot) on each transcript: compact, traceable records for original writing (fast facts,
human moments, connections, memorable lines, story devices, story spines). Its cards go at the bottom of the transcript page.

- A layer of `020_CKG` (it sits in `020_CKG\OUTBOX`): run the CKG, then pick this layer by number.
- The transcript is read in overlapping sections (split and retry on a cut-off reply); the whole-video spine comes after.
- IDs, de-duplication, vocabulary and verbatim-quote checks are done in code.
- The prompt is `STORY_MATERIAL_SYSTEM_v1.md`; standing focus goes in `FOCUS.md`.
