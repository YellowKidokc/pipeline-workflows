## Normal run

1. Put a paper in INBOX/00_PRIORITY.
2. Open BACKSIDE/questions.yaml and turn the questions on or off.
3. Open BACKSIDE/ACTIVE.yaml only when changing prompt, output, or separate-versus-bundle mode.
4. Double-click 1 RUN HERE.bat.
5. The existing workbench asks where to write results, how many calls at once, and up to five extra questions.
6. Confirm the run.
7. Open OUTBOX for the readable report, structured JSON, and receipts.

The front remains intentionally small. Configuration lives behind it; source material and results never mix with configuration.
