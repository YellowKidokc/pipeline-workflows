$$\{q_i, p_j\} = \delta_{ij}, \quad \{q_i, q_j\} = 0, \quad \{p_i, p_j\} = 0$$

This means: changing one member of a conjugate pair forces a change in the other. They are dynamically entangled by the symplectic form.
