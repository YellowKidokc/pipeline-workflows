05 Falsification Criteria

Kill conditions — any one breaks the isomorphism

  1. In Genetics: Error-free DNA replication without any repair mechanism (no proofreading, no mismatch repair, no excision repair).
  2. In Genetics: Routine, non-pathological protein-to-DNA information flow (Lamarckian inheritance at molecular level).
  3. In Theology: Manuscript tradition preserving doctrinal fidelity over 1,000+ years with a single copy and no correction mechanism.
  4. In Theology: Practice-to-Scripture authority reversal producing stable, healthy theology over generations (sola scriptura not structurally necessary).
  5. Break the topology: A structural feature present in one domain but absent in the other (stable carrier, transcription, translation, mutation, repair, redundancy, degeneracy, unidirectional flow, epigenetic expression).
Falsification would require empirical demonstration of any condition above.
