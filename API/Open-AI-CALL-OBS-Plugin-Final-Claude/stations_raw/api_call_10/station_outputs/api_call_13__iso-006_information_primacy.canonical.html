Falsification Criteria

Kill conditions — any one breaks the isomorphism

  • Show that “It from Bit” is wrong — information emerges from a sub-informational physical substrate (hidden variables, superdeterminism, or a future theory that derives quantum information from something more fundamental). If information is NOT ontologically primitive in physics, Domain A collapses and the mapping fails.
  • Show that John’s logos is not about information primacy but purely about divine personhood with no cosmological generative claim. A purely existentialist reading of the Prologue would weaken Domain B.
  • Find a physical system whose behavior cannot be described informationally. If there exists a real physical process that carries zero information content, Wheeler’s thesis fails.
