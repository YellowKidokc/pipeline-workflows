Second, jurisdiction: a true judge cannot simply pretend a wrong never happened. Third, substitution: if someone else bears the cost, mercy can appear without erasing the offense. Fourth, outside rescue: a broken system cannot heal itself from the inside. These links show that justice is real, guilt is real, mercy must not lie, and rescue must come from outside the failed system.
