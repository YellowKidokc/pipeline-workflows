Domain Specifications

Shannon information theory, Byzantine Generals Problem, fine‑tuning constants, entropy, signal/noise. The observed low‑entropy, lawful universe implies a truthful substrate.

Augustine’s privatio boni, Aquinas (defectus boni debiti), Stephen Law’s Evil‑God Challenge. Evil is parasitic on prior good; it has no independent being. The Evil‑God symmetry fails because an evil creator would be dependent, subordinate to a standard of good, and unable to produce genuine goods (oxytocin, beauty, self‑sacrifice).

Key: evil = privation · good is logically prior

Falsification Criteria

Kill conditions — if any hold, isomorphism is refuted

Evil with independent vocabulary — if any evil act can be described without reference to a violated good, the mapping fails.
Stable universe from deceptive ground — if a universe with stable laws, mathematics, and fine‑tuning could arise from a lying foundation, the information‑theoretic argument collapses.
Evil‑God symmetry restored — if the maltheist can explain oxytocin, self‑sacrifice, music, and E=mc² as means to greater evil, the asymmetry breaks.
Byzantine coordination with >⅓ traitors — if a physical system can achieve consensus with a majority of deceptive signals, the analogy fails.
Good defined as absence of evil — if good can be shown to be parasitic on evil (reverse privation), the priority order is inverted.
None of these conditions have been observed. The isomorphism stands.
