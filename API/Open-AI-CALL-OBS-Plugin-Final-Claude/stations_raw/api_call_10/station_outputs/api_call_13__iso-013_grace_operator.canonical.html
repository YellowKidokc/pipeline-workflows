Domain Specifications

Domain A · Physics

Non-Unitary Operator Algebra

A non-unitary, idempotent operator G acting on a two-state Hilbert space {|+1⟩, |-1⟩}. G = [[1,0],[1,0]] satisfies G² = G (idempotent) and G†G ≠ I (non-unitary). It is a rank-1 projection that collapses both basis states to |+1⟩. The operator cannot be generated by any internal Hamiltonian; it originates externally.

G = |+1⟩⟨+1| + |+1⟩⟨-1|  ·  G² = G  ·  G†G ≠ I

Domain B · Christian Theology

Doctrine of Grace

Prevenient grace as external divine intervention that flips the moral sign of a fallen agent from σ = -1 to σ = +1. It is complete in a single application (idempotent), irreversible (non-unitary), and requires voluntary reception (boundary condition BC8). The operation originates outside the system — God acts first.

σ = -1 → σ = +1  ·  “once for all”  ·  irrevocable

Separator Tests

Test A · Structural Preservation

PASS

Do relations survive under mapping?

Yes. Idempotency, non-unitarity, rank-1, and external origin all map directly to theological properties. The operator algebra structure is preserved in the grace doctrine.

Test B · Non-Arbitrariness

PASS

Is the mapping forced or could you swap targets?

Largely passed. Properties 1,3,4,5 are non-swappable. Idempotency (property 2) has denominational variance — Catholic sacramental grace may be non-idempotent. Overall mapping is strongly constrained.

Test C · Constraint

PASS

Does the mapping rule things out?

Yes. Pelagianism (self-generated grace) is ruled out by externality. Semi-Pelagianism is ruled out by idempotency unless α=1. Reversible grace is ruled out by non-unitarity.

Test D · Bidirectionality

PARTIAL

Does each side predict the other?

Physics → Theology: operator algebra constrains grace models (rules out Pelagianism). Theology → Physics: less clear — “once for all” selects idempotent projection but does not generate new physics. Partially bidirectional.

05

Falsification Criteria

Kill conditions — if any are met, the isomorphism is broken:

  1. Externality broken: Show that a closed two-state system can spontaneously flip from |-1⟩ to |+1⟩ without external intervention.
  2. Idempotency broken: Show that G² ≠ G for the grace operator (i.e., repeated application of grace produces a different state than single application). This would require re-salvation.
  3. Irreversibility broken: Show that the inverse G⁻¹ exists and is physically realizable (i.e., that grace can be undone).
  4. External-origin broken: Demonstrate a theological tradition where grace is genuinely self-generated and yet produces lasting moral transformation.

All four conditions are genuine — if any are met, the mapping fails regardless of theological preference.
