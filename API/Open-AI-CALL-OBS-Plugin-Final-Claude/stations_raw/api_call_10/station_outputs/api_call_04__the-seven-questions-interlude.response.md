Every claim, no matter how simple it sounds, rests on hidden layers of assumptions, definitions, and tests. This document argues that you can inspect any claim by running it through a fixed set of seven questions. The goal is not to make claims sound impressive, but to make their structure visible so anyone can see whether they hold up.

The method works like a machine with seven steps. First, you name the exact claim you are defending. Second, you expose what the claim already assumes about reality and language. Third, you define the mechanism—how the claim is supposed to work, not just what label it wears. Fourth, you identify kill conditions: the honest tests that would break the claim if they failed. The remaining three questions ask what the claim produces, what survives inspection, and what identity the surviving structure earns. Each question forces a hidden layer into the open.

The conclusion is that this sequence turns inquiry into a repeatable process. Instead of arguing about whether a claim sounds right, you can check each layer one by one. That matters because most arguments hide their weak spots. The seven questions make those weak spots impossible to miss, so you can decide honestly whether the claim deserves to stand.
