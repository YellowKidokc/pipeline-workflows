01

Domain Specifications

Domain A · Physics

Scientific Naturalism

Foundational axiom: the natural world is causally closed — every physical effect has a sufficient physical cause. This is not derived from experiment; it is the precondition for experiment. Ten unprovable presuppositions (Gauch) underwrite the method: external world, order, logic, senses, math, uniformity, truth, honesty, numbers, simplicity. Induction validates induction — structural circularity.

Domain B · Theology

Biblical Theism

Foundational axiom: God is self-existent (aseity) and has revealed Himself. Scripture self-attests (Calvin’s self-authentication); God swears by Himself (Hebrews 6:13). Knowledge is possible because the Creator designed both reality and the mind. Circularity is structural: the ultimate starting point cannot be validated from outside without displacing it.

03

Separator Tests

Test A · Structural Preservation PASS

Do relations survive under mapping? The circularity relation in physics (induction→induction) maps to the circularity relation in theology (Scripture→Scripture). Both systems exhibit the same dependence pattern. ✓

Test B · Non‑Arbitrariness PASS

Is the mapping forced? The axioms of causal closure and divine aseity occupy identical logical positions: ultimate, unprovable, load‑bearing. Swapping targets (e.g., atheism ↔ Buddhism) breaks the structural match. ✓

Test C · Constraint PASS

Does the mapping rule things out? It excludes any system that claims external validation of its foundation. It also rules out the claim that science has no axioms. The mapping constrains both domains equally. ✓

Test D · Bidirectionality PASS

Does each side predict the other? If naturalism requires unprovable axioms, then by structural necessity theism will also require an unprovable starting point — and vice versa. The pattern holds in both directions. ✓

05

Falsification Criteria

Kill conditions — the isomorphism is falsified if any of the following hold:

  • Science can prove its own foundational axioms using its own method (induction validated without induction).
  • Theology can provide an external, non‑circular validation of Scripture that does not rely on Scripture’s own authority.
  • A third system is found that rests on zero unprovable axioms (a self‑validating foundation).
  • The mapping between causal closure and aseity is shown to be arbitrary — a different target fits equally well without structural loss.
  • Either domain can be reduced to the other without remainder (eliminative reduction).
If any condition is met, the isomorphism is downgraded to correspondence or abandoned.
