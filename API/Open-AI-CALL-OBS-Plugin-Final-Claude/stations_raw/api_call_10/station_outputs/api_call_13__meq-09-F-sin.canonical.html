05 Falsification criteria

  • If a non‑sin theological concept also satisfies dσ/dt ≥ 0 — mapping becomes non‑unique.
  • If the sin‑state σ is not a monotonic function of time — the differential structure collapses.
  • If a thermodynamic system violates the second law — the physical anchor dissolves.
