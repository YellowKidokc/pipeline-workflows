**Break condition**

### Reject external grace

The works-based sign-flip becomes impossible under the framework's non-unitary requirement.

Think of it like this: **Grace changes the shape of the ground under your feet.** If you reject that, you're trying to walk uphill on a flat slope — the sign-flip (the reversal of direction) can't happen because the ground itself hasn't tilted.

**Break condition**

### Reject information primacy

The system falls back into circular definitions or regress because rival primitives borrow informational structure.

Like a **radio signal through static** — if you deny that the signal is primary, you still need the signal to explain why the static is there. The rival starting points secretly use the same radio channel to make their own case.

**Break condition**

### Reject Time Wall

**Break condition**

### Reject coherence conservation
