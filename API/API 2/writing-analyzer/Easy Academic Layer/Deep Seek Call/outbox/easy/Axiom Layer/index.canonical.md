# From Axioms to Closure

This layer is easiest to read when you follow the same order every time: axioms, definitions, theorems, lemmas, extended framework, and closure. The detailed pages already exist. This page gives you the clean map.

**Purpose:** To help you navigate the structure  
**Style:** Same shell, same audit footer at the bottom  
**Order:** Start with the premise, end with the closure

## Reading Order

- **[Layer 0: Axioms](./axioms.html)** — What the system starts by asserting, and what it cannot prove from itself.
- **[Layer 1: Definitions](./definitions.html)** — What the system means by its terms before it starts proving anything.
- **[Layer 2: Theorems](./theorems.html)** — What follows when you run the axioms and definitions through the rules.
- **[Layer 3: Lemmas](./lemmas.html)** — The support results that keep the larger claims from floating loose.
- **[Layer 4: Extended Framework](./axioms-layer-3-extended.html)** — The higher-load claims: grace operator, master equation, worldview filter.
- **[Layer 5: Closure](./axioms-closure.html)** — The endpoint where the architecture loops back to its starting ground.
- **[Tooling: 7Q Method Explorer](./7Q%20Axioms.html)** — The classification and falsification front door for testing claims inside the Axiom Layer.

## What This Fixes

- One conceptual page for each stage of the stack.
- A clear distinction between what is asserted, defined, derived, and supported.
- A cleaner handoff for readers who do not want to start in the middle of the proof chain.

## What Stays Canonical

- The existing detailed pages remain the deeper reference layer.
- The canonical derivation chain remains the source text for the structure.
- The audit footer stays on every page as the last-pass check.
- The 7Q Method Explorer stays as a direct tool entry, not a separate site page.

## Where to Start

If you only want the clean surface map, read this index first. If you want the substance, follow the same order and open the detailed pages as needed.
