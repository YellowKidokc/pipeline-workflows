What this folder is

This folder is a working research and engineering workspace for the "Faith Through Physics" / POF 2828 project, combining paper-analysis templates, epistemic scoring frameworks, Lean 4 axiom inventories, and Python pipeline scripts. The main threads are: (1) a paper-metric and template system (v0.3/v0.4 master templates, metric registries, question inventories) for scoring and rendering papers; (2) epistemic and theological frameworks (Fruits of the Spirit canonical spec and formalization, CKG atom templates); (3) formal verification assets (Lean axiom manifests, mode-classification ledgers); and (4) automation tooling (YouTube subtitle extraction, transcript indexing, turbo pipeline runner, epistemic intake, χ/Qi audit engine). Finished items include the migration receipt (verified, hash-checked) and the metric registry specs, while most templates, the Fruits formalization, the χ/Qi engine, and the Codex consolidation prompt remain drafts or specs. There are clear duplicates: `paper_metric_registry.json` appears twice with near-identical descriptions, and the master paper template exists in several overlapping versions (`02_MASTER_PAPER_TEMPLATE_v0.3.md`, `02_MASTER_PAPER_TEMPLATE_v0.4.md`, `MASTER_PAPER_TEMPLATE_v0.3.md`, `02_MASTER_PAPER_RENDERED_FORMAT.md`) that should be reconciled to one canonical version. `EMPTY_TRANSCRIPTS.md` flags 251 failed subtitle fetches needing re-runs, and the axiom mode-classification ledger records 136 entries moved out of the Lean core plus one dropped duplicate. Open first: `02_MASTER_PAPER_TEMPLATE_v0.4.md` (the current canonical template), `Fruits_of_the_Spirit_Epistemic_Rating_System_Canonical.md` (the core framework spec), and `paper_questions_and_metrics.md` (the metric inventory that ties the pipeline together).
