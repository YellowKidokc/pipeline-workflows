# Prompt Box

Double-click `PROMPT_BOX.bat` for the standard-library Tkinter UI. Pick a target and profile, enter a prompt, and preview or write a sidecar YAML instruction. **Save as new prompt** creates a reusable profile in the YouTubeChannelRefinery packet. Every submission is appended to its `LOGS/prompt_box.jsonl`. Set `PIPELINE_WORKFLOWS_ROOT` when this tool is copied outside the repository.
