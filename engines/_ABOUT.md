# 06 — Preference Engines

## What this folder is

Preference and recommendation engines (P01–P07). These run as persistent services.

## Process

Start all engines: 07_ORCHESTRATOR/START_ALL_ENGINES.bat
Engines serve the dashboards in 08_DASHBOARDS and write to 09_DATABASES.
Each engine has its own port in the 20xxx range.
