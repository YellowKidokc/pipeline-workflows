## ▼ Alternative Primitive Branches

**Alternative: Matter primitive**
Dead-end. Matter can only be described through informational properties — mass, charge, spin, position. You can't talk about matter without using information to describe it.

**Alternative: Mathematics primitive**
Dead-end. Math describes relationships between things, but it doesn't create a substrate (a real medium) for those relationships to exist in.

**Alternative: Consciousness primitive**
Dead-end. Consciousness still requires distinguishable states and a processing substrate. You can't have thoughts without something to think about and something to think with.

**Alternative: Information emergent**
Dead-end. "Emergence" means something arises from a prior system. But if information emerges, you need a prior structured system — so you're just pushing the question back one step. The regress (infinite chain of causes) remains open.
