## Glossary

#### Superposition

A quantum state that is the simultaneous combination of multiple possible outcomes. Before measurement, the system holds all possibilities at once. Measurement forces it into one.

#### Wavefunction Collapse

The instantaneous, irreversible transition from superposition to a single definite outcome when a quantum system is measured. The other possibilities vanish.

#### Decoherence
