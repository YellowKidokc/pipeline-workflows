## What this page is

Lean 4 is a formal proof assistant (a computer program that checks if logical arguments are correct). Mathematicians at Microsoft Research, DeepMind, and leading universities use it. When a proof compiles in Lean, it means the logical structure has been verified by the kernel — a small, trusted core that checks every step. No human judgment is involved in the verification. No rhetoric. No interpretation. The machine says yes or no.

Every theorem listed below compiled clean. Zero `sorry` — Lean's marker for "I skipped this step." Nothing was skipped. Nothing was assumed without proof.

### What this does not prove

Lean verifies logical structure, not empirical truth (whether something matches real-world observations). It proves: "Given these definitions and starting assumptions, these theorems follow by logical necessity." It does not prove that the ten laws are true descriptions of reality, that each physics/theology pair matches the physical world, or that the framework's theological claims are correct.

What it does prove: the internal architecture is formally consistent, the structural claims hold under any algebra satisfying the starting assumptions, and no one can dismiss this as "just analogies." The algebra is real. The proofs are machine-checked.
