## What Coherence Means in Physics

In physics, **coherence** means how much the parts of a system are lined up or working together. A coherent system is one where the pieces act as a team instead of doing their own thing.

This is not just a nice comparison. You can measure it.

In a laser, light particles (photons) are coherent when they all have the same wave pattern and frequency. In a superconductor, electrons are coherent when they form pairs called Cooper pairs. In a magnet (ferromagnet), the tiny magnetic spins of atoms are coherent when they all point the same way.

## The Order Parameter (χ)

Physicists measure coherence using an **order parameter** — a number you can measure. It equals **zero** in the messy, disordered (high-entropy) phase. It is **non-zero** in the ordered (low-entropy) phase. And it changes **sharply** at the phase transition.

## The Phase Transition

When a system crosses its **critical threshold** (Tc), coherence collapses:

### Phase Transition Equation

χ ∝ |T − Tc|β for T < Tc (ordered phase)

χ → 0 for T > Tc (disordered phase)

T = temperature | Tc = critical temperature | β = critical exponent (typically 0.3–0.5)

*What this equation says in English:* The order parameter (χ) is proportional to the difference between the current temperature (T) and the critical temperature (Tc), raised to a power (β). This only works when the system is in the ordered phase (T < Tc). When the system is in the disordered phase (T > Tc), the order parameter drops to zero.

This transition is **sudden, not gradual.** It is **universal across systems** — same math, different materials. And it is **predictable** once you know Tc.

## A Concrete Example: The Superconductor

**Below Tc — Ordered**
Electrons form Cooper pairs. Electrical resistance drops to zero. The system shows quantum coherence (weird quantum behavior) at a large, visible scale.

**Above Tc — Disordered**
Cooper pairs break apart. Resistance comes back. Coherence is lost.
