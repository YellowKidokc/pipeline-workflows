## The Shannon Isomorphism

The Universal Signal Persistence Framework (USPF) is not just a custom scoring system. It is a formal application of Claude Shannon's Channel Capacity Theorem from 1948 to the problem of how signals survive through history.

C = B · log₂(1 + S/N) [Shannon, 1948]
Strength = S · M · ln(1 + P) [USPF]

Here's what that means in plain English: The first equation is Shannon's formula for how much information can get through a noisy channel. The second equation is the USPF formula for how strong a signal is after surviving through history. The mapping is direct — signal integrity (S) times mechanism strength (M) equals net signal power, and survival pressure (P) equals the signal-to-noise ratio. The logarithmic part captures how the channel handles noise. This is not a metaphor. It is the same mathematical structure, just applied to a different kind of channel.

## The Three Variables

| Variable | Shannon Analog | Definition |
|---|---|---|
| S — Integrity | Signal power | What fraction of the original signal survives intact and can still be understood |
| M — Mechanism | Error-correction / amplification | How the signal protected itself: redundancy, independence, ability to be reconstructed |
| P — Pressure | Signal-to-Noise Ratio | Total entropy load survived: suppression, catastrophe, cultural discontinuity, medium transitions |

## Why Multiplicative, Not Additive

The variables multiply rather than add. This is on purpose. If any single dimension collapses to zero, the entire score collapses to zero. A signal that lasted forever but lost all integrity scores zero. A signal that was perfectly preserved but never faced any pressure scores zero. Neither condition alone is enough. This prevents any single variable from making up for complete failure in another.

Think of it like a chain — if one link breaks, the whole chain breaks. No single link can carry the load if another link is completely gone.

## Anomaly Scoring

Raw strength scores are converted to Z-scores (a statistical measure of how far from average a score is) against a category-locked baseline. Baselines are set from the existing registry before any new signal is entered. This prevents the comparison class from being rigged to favor a predetermined result.

| Classification | Z-Score |
|---|---|
| Extreme Anomaly | > 4.0σ |
| Highly Anomalous | 2.5 – 4.0σ |
| Notable | 1.5 – 2.5σ |
| Normal | -1.5 – 1.5σ |
| Rapid Decay | < -1.5σ |

**METHODOLOGICAL HONESTY**

This framework measures signal robustness — how well something survived transmission through a hostile channel. It does not directly measure truth. Persistence is not proof that something matches reality. The framework identifies structurally non-arbitrary signals that demand an explanation. What that explanation is remains a separate question. The anomaly score is the start of a question, not the end of one.

## Pre-Registration Requirement

To be scientifically defensible, all variable definitions, baseline categories, and anomaly thresholds must be locked before the signal of interest is entered into the system. The registry enforces this by computing baselines from existing data prior to any new addition.
