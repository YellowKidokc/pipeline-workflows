### Foundation Spine

**Axiom A1.1** — Something exists rather than nothing.
If you try to deny this, you're using existence to deny existence. It's self-refuting.

**Axiom A1.2** — Existence requires distinction.
For anything to be knowable, it has to be different from something else.

**Axiom A1.3** — Distinguishability is information; information is primitive.
This is a critical branching point. We're saying information is the most basic thing.

**Definition A2.1 / D2.1** — Information needs a substrate (a base layer to exist on). That substrate is the Logos field.
We're choosing a self-grounding substrate — something that doesn't need anything else to exist.

**Commitment A2.2** — Self-grounding chosen.
This is an explicit choice, not something we're trying to sneak in as a hidden derivation.

**Derivation** — 189 axioms unfold from the constraints of substrate, coherence (how things hold together), and closure (how systems complete themselves).
The whole architecture grows from this compressed starting point.

### ▼ Alternative Primitive Branches

**Alternative: Matter primitive**
Dead-end. You can only describe matter using informational properties — mass, charge, spin, position. Matter doesn't explain itself.

**Alternative: Mathematics primitive**
Dead-end. Math describes relationships between things, but it doesn't create a real substrate. It's a language, not a substance.

**Alternative: Consciousness primitive**
Dead-end. Consciousness still requires distinguishable states and a processing substrate. You can't have thoughts without something to think about.

**Alternative: Information emergent**
Dead-end. "Emergence" means something arises from a prior structured system. That just pushes the question back — where did that prior system come from?
