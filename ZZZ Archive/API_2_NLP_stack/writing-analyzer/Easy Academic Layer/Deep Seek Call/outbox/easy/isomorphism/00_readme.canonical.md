# Isomorphism Registry

A collection of records showing shared patterns (structural isomorphisms) between different fields of study in the Theophysics framework.

## What This Is

Each ISO record describes a claimed structural correspondence (shared pattern) between two different areas of knowledge. Every record includes: the mapping between domains, a swap test, predictions that go both ways, conditions that would prove it wrong, and an honest classification of how strong the evidence is.

## How We Test Claims

All records are checked against the **Four-Test Protocol** (HYP-ISO-001):

1. **Prediction Constraint** — Does the pattern let us predict things in both domains?
2. **Symmetric Breaking** — If you break one domain, does the other break the same way? (Like the slope of a hill — if the ground tilts one way, everything on it tilts that way too.)
3. **Connection Density** — How many independent connections exist between the two domains? (7+ connections means it's very unlikely to be just chance.)
4. **Falsifiability Invitation** — Does the mapping clearly state what would destroy it?

Full protocol: [04_THEOPYHISCS/Doctor thesis/Isomorphic/HYPOTHESIS The Isomorphism Discrimination Method](.html)

## Rules

- An isomorphism that can't be falsified (proven wrong) isn't an isomorphism — it's a belief.
- "Analogy Only" is not a failure. It's an honest classification.
- The swap test is mandatory. If the roles are interchangeable, the mapping is arbitrary (meaningless).
- "OBSERVATION CONFIRMED, MECHANISM UNSOLVED" is a valid status. Seeing the pattern comes before explaining it.
