## What Coherence Means in Physics

In physics, **coherence** means how much the parts of a system are lined up or working together. A coherent system is one where the parts act as a team instead of doing their own thing.

This is not just a nice way to describe things. You can measure it.

In a laser, light particles (photons) are coherent when they all have the same wave pattern and timing. In a superconductor, electrons are coherent when they form pairs called Cooper pairs. In a magnet (ferromagnet), the tiny magnetic spins of atoms are coherent when they all point the same way.

## The Order Parameter (Ï‡)

Physicists measure coherence using an **order parameter**. This is a number you can measure. It equals **zero** in the messy (high-entropy) phase. It is **non-zero** in the ordered (low-entropy) phase. And it changes **sharply** at the phase transition — like a light switch, not a dimmer.

- **Ferromagnet:** Ï‡ = total magnetic alignment (net magnetization)
- **Superconductor:** Ï‡ = density of Cooper pairs
- **Crystal:** Ï‡ = how regular the atomic pattern is (lattice order)

## A Concrete Example: The Superconductor

**Below Tc — Ordered:** Electrons form Cooper pairs. Electrical resistance drops to zero. The system shows quantum coherence (perfect teamwork at the atomic level) on a large scale.

**Above Tc — Disordered:** Cooper pairs break apart. Resistance comes back. Coherence is gone.
