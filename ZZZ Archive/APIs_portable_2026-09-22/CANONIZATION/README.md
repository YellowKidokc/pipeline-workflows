# Canonization

- **INBOX**: source copies and candidates to examine.
- **REVIEW**: claim records, supporting evidence, objections, and proposed decisions.
- **OUTBOX**: prepared papers and ledgers awaiting a decision.
- **ADMITTED**: the versions David has explicitly endorsed, with their stated scope.

These folders start empty. The Evidence and Lean APIs do not automatically admit claims.
This is the handoff structure for the next part of the workbench, not a completed claim-admission engine.
