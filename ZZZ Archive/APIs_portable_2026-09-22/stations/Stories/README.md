# Stories station

Drop one UTF-8 story into `INBOX`, or an explicitly numbered nested series into `INBOX/SERIES`. Series ordering is lexical by relative path (`001-...`, `002-...` recommended); files are independent and no prior-file context is silently sent. Edit the four plainly named prompts. The original is unchanged and preserved by hash; faithful and speculative outputs are separate.

Start with `SETUP.bat`, then `RUN_ONCE.bat`. The bundled mock provider spends no credits; select and configure a live provider deliberately.
